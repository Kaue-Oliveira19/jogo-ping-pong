Esse projeto é uma implementação simples de um jogo clássico de Ping Pong, que foi desenvolvida totalmente em Python utilizando a biblioteca
Pygame. O objetivo do trabalho é aplicar conceitos básicos de computação gráfica. Esse jogo cria uma experiência jogável para dois jogadores
no mesmo teclado.
O jogo consiste em duas raquetes posicionadas nas laterais da tela e uma bola que se movimenta entre elas. Cada jogador deve controlar sua raquete para impedir que a bola ultrapasse seu lado da tela. Caso isso aconteça, o adversário recebe um ponto e a partida é reiniciada. 

O projeto foi desenvolvido como atividade prática para treinar conceitos básicos da Matéria de Computação Gráfica, por exemplo:

- Elementos gráficos 2D
- Coordenadas na tela
- Posição de objetos
- Primitivas gráficas

## Como Funciona?
Durante a partida, dois jogadores competem controlando suas respectivas raquetes. A bola se desloca automaticamente pela tela e rebate ao colidir com as bordas superior e inferior do cenário. Quando a bola encontra uma das raquetes, sua direção é invertida, simulando o rebote Caso a bola ultrapasse uma das laterais da tela, o ponto é contabilizado para o jogador adversário. Após a pontuação, a bola retorna ao centro da tela com uma nova direção aleatória, iniciando outra rodada. O jogo continua indefinidamente até que a janela seja fechada.

### Controles
Os jogadores utilizam o teclado para movimentar suas raquetes verticalmente.

- Jogador da esquerda (raquete azul):  
    W: mover para cima  
    S: mover para baixo

- Jogador da direita (raquete vermelha):  
Seta para cima: mover para cima  
Seta para baixo: mover para baixo  

## Requisitos
Para executar o projeto é necessário ter instalado:
- Python 3 (nesse projeto foi usado a versão 3.10.11)
- Biblioteca Pygame(nesse projeto foi usada a versão 2.5.2)

## Como Executar? 

1. Baixe ou clone o projeto.
2. Abra o terminal na pasta do projeto.
3. Instale as dependências por **pip install -r requirements.txt**
4. Execute o arquivo principal: ping-pong.py
